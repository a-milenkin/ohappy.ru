# ohappy.ru

Персональные песни-поздравления: анкета → текст (Claude) → музыка (Suno через kie.ai) → страница-подарок по ссылке.

## Запуск

```bash
cp .env.example .env.local   # заполнить ключи
npm install
npm run dev
```

Без `KIE_API_KEY` Suno работает в демо-режиме (тестовый трек), без `ANTHROPIC_API_KEY` — шаблонный текст.
Без `KV_REST_API_URL` песни хранятся файлами в `.data/` — на своём сервере (VPS) этого достаточно.

## Продакшн

```bash
npm ci && npm run build && npm start   # порт 3000, за nginx
```
